Require US citizenship? No F-1/J-1/CPT/OPT allowed? ITAR? This extension lights your page red so you can skip it.

Works on any site. Just toggle it on or off depending on whether you're job searching.

## Instructions

Ask Claude or Codex to clone this.

Or clone it yourself and load it unpacked in Chrome or another Chromium browser:

```bash
git clone https://github.com/asherchok/citizenship-flag.git
```

1. Open `chrome://extensions` and turn on Developer mode.
2. Click **Load unpacked** and pick the `citizenship-flag` folder.

It only matches keywords, so read the posting before you rule it out.
